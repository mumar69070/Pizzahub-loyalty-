Admin sign-in (Firebase)

Needed to see customers from all devices. Create the account once in the Firebase console: Authentication, then Sign-in method, enable Email/Password, then Users, Add user.

Signed in asNot signed in

Database rules

In the Firebase console, open Realtime Database → Rules, paste this, and press Publish. Without it, Firebase blocks reading or writing (permission denied).

What these rules do: customers can read and write only their own card (they need to know the mobile number), anyone can add an order request, and only a signed-in admin can read the full customer list and all orders or delete an order, so phone numbers are not public. Deals and banners are still writable by anyone who has the page's code. To lock that too, change the content line ".write": true to ".write": "auth != null" once admin sign-in works.

How it works

  1. Every change in the Deals and Banners tabs is saved on this device first, then sent to Firebase right away.
  2. Customer phones listen to Firebase live, so a new deal appears on their screen within a moment, with no refresh.
  3. If a phone is offline, it keeps showing the last deals it received and updates itself when the connection returns.
  4. Customer cards are saved in Firebase too, so a customer who logs in on a new phone with the same mobile number gets the same card, and you see every customer here live.

Tip: uploaded images are stored inside the database and make it large. An image link (https://…) in the deal and banner forms keeps it small and fast.
